# Admin expense entry

Admin can use **Appointments > Expenses > Add expense** to record a company expense or select an optional technician and booking. A receipt is required. JPG, PNG, WEBP and PDF files are stored in the protected MongoDB receipt store, with signature validation and a 5 MB limit. Admin entries are saved as approved and record the signed-in administrator as creator and approver. Technician submissions keep their existing pending-approval workflow; secretary views do not expose the creation form and the creation API requires admin.

The API validates money, dates in Philippine time, description length, fuel details, existing booking links, and active technicians before storing a receipt. The form token and signed-in actor determine a unique expense ID, so retries and concurrent submissions cannot create duplicate records. Retrying with changed details returns a conflict. Failed record creation removes its new receipt, including the unused receipt from a losing concurrent request.

Saving refreshes the all-expenses view and approval totals. Approved-today totals use Philippine day boundaries. Company expenses are labelled separately from technician expenses, and creator names are shown. New admin entries contribute to operating expenses even when linked to bookings with recorded direct costs; the existing exclusion of mirrored technician material purchases remains in place.
